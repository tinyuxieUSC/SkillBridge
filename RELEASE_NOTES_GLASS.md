# Glass Edition release notes

This is a **UI/UX revision**, not a rewrite of the underlying business logic. Existing API endpoints, user progress storage key, challenge content and case rubric logic remain compatible with Studio PRO.

Highlights: top nav, responsive mobile menu, immersive editorial home, translucent cards, tactile topic bubbles, soft branded color families, improved practice card controls, dark styling, reduced-motion preference support, and fixed case-search blur issue.

Screenshots provided separately for reference; they depict the actual browser-rendered app with offline mode (not generated UI mockups).
